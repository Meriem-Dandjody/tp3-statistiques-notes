# TP 3 — Statistiques d'une série de notes

Programme C++23 qui lit les notes d'une UE et affiche : note minimale et maximale, moyenne, écart-type, nombre et pourcentage d'admis, et la répartition par mention sous forme d'histogramme.

## Compilation
'''
g++ -std=c++23 -Wall -Wextra -o tp3 tp3.cpp
./tp3
'''
Nécessite GCC 14+ ou Clang 18+ (pour `std::print`).
